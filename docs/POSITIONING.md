# Positioning — Iris

**One-liner:** Image facts with pixel-level proof.

- **User:** an agent that must read a screenshot, UI capture, form, diagram, chart or photo without a generative vision model.
- **Job:** return deterministic metadata, OCR boxes, layout blocks, regions, crops and image diffs as citeable facts.
- **Promise:** geometry and locators are authoritative; optional OCR, captions and open-vocab objects are explicit and scored.
- **Identity:** package `@sylphx/iris`, bin `iris`, MCP `io.github.SylphxAI/iris`, site <https://sylphxai.github.io/iris/>.
- **Companion tools:** Citra, Iris, Cue, Spine, Locus and Lookout are independent products composed through public MCP and SDK contracts.

See [vision.md](./vision.md) and [capabilities.md](./capabilities.md) for the destination and the owned capabilities. [TOOL_SURFACE.md](./TOOL_SURFACE.md) is the tool policy and [EVIDENCE_CONTRACT.md](./EVIDENCE_CONTRACT.md) is the result contract.
